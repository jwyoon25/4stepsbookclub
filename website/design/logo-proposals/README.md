# 4steps Book Club — Logo Proposal 02

This is a proposal set only. The committed production logo remains unchanged in `public/images/`.

The three directions deliberately answer three different questions about the brand:

1. Is 4steps primarily a clear, repeatable learning **method**?
2. Is it primarily a four-person reading and discussion **community**?
3. Is it primarily a thoughtful, literary **editorial brand**?

The palette stays fixed across all three so the logo ideas—not color preference—drive the decision.

## 01 — Four Beats

![Four Beats lockup](./01-four-beats-lockup.svg)

**Idea:** Four equal beats stand for READ, THINK, SPEAK, and WRITE. They are deliberately equal rather than ascending, because this is a repeatable method—not a growth chart.

- **Personality:** clear, modern, methodical
- **Best quality:** the brand name stays largest and clearest in a narrow mobile header
- **Honest risk:** the four beats can feel decorative unless the four-step method is already understood
- **Compact mark:** [01-four-beats-mark.svg](./01-four-beats-mark.svg)

## 02 — The Reading Table

![The Reading Table lockup](./02-reading-table-lockup.svg)

**Idea:** Four open seats face one shared sentence. It makes the maximum-four-student live class—not a generic book icon—the center of the identity.

- **Personality:** warm, participatory, human
- **Best quality:** owns the program's most concrete classroom differentiator
- **Honest risk:** without the story, the compact mark may first read as a table, flower, or collaboration symbol
- **Compact mark:** [02-reading-table-mark.svg](./02-reading-table-mark.svg)

## 03 — The Imprint

![The Imprint lockup](./03-imprint-lockup.svg)

**Idea:** A literary masthead treats each student's thinking as authored work worth reading, discussing, editing, and publishing with care.

- **Personality:** thoughtful, literary, premium
- **Best quality:** strongest match for the website's contemporary reading-room direction
- **Honest risk:** it communicates academic/editorial credibility more immediately than the four-person class format
- **Compact mark:** [03-imprint-mark.svg](./03-imprint-mark.svg)

## Quick comparison

| Direction | Leads with | Mobile name recognition | Distinctive idea | Warmth | Academic credibility |
| --- | --- | --- | --- | --- | --- |
| Four Beats | Method | Strongest | Strong | Moderate | Strong |
| Reading Table | Community | Strong | Strongest program link | Strongest | Strong |
| The Imprint | Authorship | Strong | Strongest visual voice | Strong | Strongest |

## Recommendation lens

- Choose **Four Beats** if parents must understand and remember “four connected stages” first.
- Choose **The Reading Table** if the four-student live discussion format is the most ownable business advantage.
- Choose **The Imprint** if the long-term ambition is a distinctive reading, writing, and publishing-style education brand.

Before selecting, show the mobile board to several target parents for five seconds without explaining the concepts. Ask what the name is, what age/service they assume, and which feels most trustworthy. Then explain each rationale and test which one they can repeat back in one sentence.
